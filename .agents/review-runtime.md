# Codexのレビュー実行条件

このファイルはCodex用の実行指示であり、共通レビュー方針や権限設定ファイルではない。

- ユーザー指定のモデル・推論量を使う。未指定なら実行セッションの設定を継承する。指定が利用できない場合は勝手に別の値へ置き換えず未完了とする。実効値を確認できなければ不明と報告する。
- [共通レビュー方針](../.ai-config/review/policy.md)の読取専用の運用を親・子ともに守る。既存のsandbox・認証・承認設定を変更せず、書込を許可する承認は行わない。
- 親・子の実効モデル・推論量・sandboxや外部ツールの無効化を確認できないことだけを理由に開始を中止しない。確認できない値は未確認と報告し、読取専用sandboxや外部変更ツールの無効化が保証されたとは扱わない。
- 子agentにも同じモデル・推論量と共通レビュー方針を渡す。モデル・推論量は親側で指定し、子agentの設定ファイルやskill本文だけで権限を変更できるとは扱わない。
- 読取の開始順序と手段は[AGENTS.md](../AGENTS.md)を正本とし、全文読んで適用する。初期読込からGit読取限定を守る。
- skillを読むだけでは子agentは起動しない。1ラウンドにつき親が独立した子agentを3人起動し、それぞれが指定された観点のskillを読んで1回実行し、親は全結果を待つ。会話履歴に依存しない入力を渡す。Codex組込みの子agentも利用でき、ネストしたCLI起動やOSによる書込拒否の実測は必須にしない。
- 委譲できない観点は未完了とする。親による代行を独立レビューと数えない。
- 起動時のモデル・推論量・権限条件と、実際に確認できた値を区別して報告する。

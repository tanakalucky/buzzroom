# room

ルームの作成・参加・quizmaster(司会)の管理に関する機能仕様。

## 作成

- ルーム作成時にパスワードを設定する。
- 作成時に本人の表示名も設定する。ルーム名は入力しない。
- 作成者はそのルームの初期 quizmaster になる。

## 参加

- 参加には招待 URL とパスワードの両方が必要。招待 URL を知っているだけでは参加できない(URL にパスワードを含めない)。
- 参加者はニックネームのみで参加する。アカウント登録は不要。
- 招待URLの同じルーム画面で本人名とパスワードを入力する。独立した参加ページは作らない。名前は前後空白を除き1〜24文字、重複可能。名前を本人確認や一意IDに使わない。
- URLコピーはルームURLだけを対象とし、名前・パスワード・セッショントークンを含めない。
- ラウンドの途中でも参加できる(締め切りはない)。参加直後から早押しに参加できる([features/buzzer.md](buzzer.md) の「途中参加」を参照)。

## quizmaster

- 現在の quizmaster は、参加者の誰かに quizmaster を譲渡できる。
- quizmaster は早押しに参加できない(ボタンを押せない)。
- quizmaster が切断した場合、自動で他の参加者に役割が移ることはない。本人の復帰を待つ。

## 再接続

- 同じブラウザからの再接続では、参加者としての識別(ニックネーム・採点カウント・現在ラウンドの解答権制限)が復元される。
- ルーム単位のHttpOnly CookieとRoomDO内のランダムトークンのハッシュ照合を使う。名前を本人証明にしない。
- 発行から固定24時間はブラウザ終了後も復帰可能。アクセスや再接続で期限を延長しない。Cookieの期限だけでなくサーバーで検証し、接続中の期限切れでも操作を拒否・切断する。
- 期限切れ後はパスワードで再入室し、別の参加者となる。ルームや既存得点は削除しない。ルーム自体の有効期限とは別であり、その運用期限は未決のまま。
- CookieはSameSite=Strict・ルーム配下のPath、本番HTTPSではSecure。トークンはURL・ログ・公開スナップショットへ含めない。

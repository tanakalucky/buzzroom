# buzzer

早押しキューと解答権、ラウンドのリセットに関する機能仕様。

## キュー

- 参加者がボタンを押すと、RoomDO がその押下リクエストを受信した順序でキューに入る(クライアント側の押下時刻や、サーバ到着時刻同士の比較では判定しない。同着の補正も行わない)。
- quizmaster はボタンを押せない(キューに入らない)。
- カード右上の数字は当該ラウンドの押下順。回答権の移動と分離し、誤答後も再番号付けしない。未押下者はバッジなし。新ラウンドで履歴を消す。
- 参加者の早押しボタンは画面下部に固定し、safe areaと本文末尾の余白を確保する。接続状態と効果音クレジットはルーム枠の末尾に置き、固定ボタンに隠れないための余白は枠の外側に確保する。入室フォームでは表示しない。入力・ダイアログ操作を妨げない。

## 解答

- キュー先頭の参加者が解答権を持つ。
- **誤答**: その参加者の誤答数(wrongcount)を +1 する。その参加者は今ラウンドの間、再度ボタンを押せなくなる(ブロック)。解答権はキューの次の参加者に移る。
- **正解**: その参加者の正解数(correctcount)を +1 し、即座に次ラウンドを開始する(下記「ラウンドのリセット」と同じ効果)。

## キューが尽きたとき

- 全員が押してすべて誤答し、キューが空になった場合は、host(quizmaster)の手動リセットを待つ。自動では次ラウンドに進まない。
- まだ誰も押していない参加者がいる限り、キューが空でも解答権が回っていない参加者はボタンを押せる(ラウンドは継続する)。

## ラウンドのリセット

新ラウンドの開始(正解による自動開始、または host の手動リセット)は、いずれも次を行う。

- キューを空にする。
- 今ラウンドの誤答ブロックをすべて解除し、全参加者が再度ボタンを押せる状態にする。
- correctcount・wrongcount の合計値は保持する(リセットしない)。

## 途中参加

- ラウンドの途中で参加した参加者も、参加直後からそのラウンドでボタンを押せる。

## 再接続

- 同じブラウザからの再接続では、現在ラウンドでの解答権制限(誤答によるブロック中かどうか)が復元される。

## 効果音

- 司会・参加者は各端末の「音をオン」で有効にする。初期状態と再読み込み後はオフ。他の端末の設定は変えない。オン操作だけでは音を鳴らさず、「音をオフ」で停止できる。
- サーバーが押下を受理するたびに早押し音、正解・不正解の判定を受理したときにそれぞれ異なる短い電子音を1回鳴らす。待ち行列への追加も対象。ローカル押下時、連打などで拒否された操作、解答権の移動だけでは追加再生しない。
- 効果音はOtoLogicの「クイズ ボタン02-1（マルチ）」「クイズ ピンポン02-1（速）」「クイズ ブザー02-1（中）」を、それぞれ早押し・正解・不正解に使う。MP3の内容は未改変で同梱し、同一originから取得する。出典・作者・CC BY 4.0・元ファイル名は [帰属資料](../../public/sounds/otologic/ATTRIBUTION.md) に記載する。
- 「音をオン」の操作でWeb Audio APIを開始し、3音の取得・decodeがすべて完了すると、その後の受理イベントに応じた再生が可能になる。準備完了・再オン・失敗後の再試行だけでは音を鳴らさない。受理のたびに通信せず、読み込み中に届いた音も後から鳴らさない。準備中は「音の準備を中止」で取り消せる。オフ・画面終了時は再生中の音と読み込みを止め、音声リソースを解放する。取得・decodeの失敗時も再試行できる。
- 接続状況の下に全役割共通で「効果音：OtoLogic / CC BY 4.0」と「詳細」を表示する。詳細dialogに作者、3素材の名前・枝番、配布元、利用規約、ライセンス、未改変であることを表示する。Escapeまたは閉じる操作で元の「詳細」にフォーカスを戻す。聞きやすさ・音量は実際の端末で試聴して確認する。
- 手動リセット・採点編集・司会交代は無音。途中参加・再接続・再読み込みで過去の音は鳴らさず、切断中やオフ中の音を後から再生しない。
- ブラウザの音声制限などで再生できない場合も、早押し・採点・状態表示は継続する。案内に従い「音をオン」で再試行できる。端末間の厳密な再生時刻の一致や、バックグラウンドでの再生は保証しない。
- 音色選択・音量調節は含めない。早押しボタンは送信中・押下済み・誤答ロック中・切断中には非活性となる。
